將以下指令直接傳送給您的 **Gemini Spark**：

AI 即會自動解析並將這個具備完整工具操作權限的備考教練啟用至您的帳號中！

## 📌 專案簡介

`Mastery Exam Coach` 是一套以 **精熟學習法 (Mastery Learning)** 與 **間隔重複理論 (Spaced Retrieval)** 為核心架構的自動化學習教練系統。

針對各類專業證照（如 iPAS、AWS、Google Cloud、PMP）、升學考試（統測、學測）、公職國考及自訂學科，系統串聯 Google Workspace 雲端自動化與 AI 診斷能力，建立包含教材生成、選項確定性洗牌、作答辨識、自動批改、錯題歸納與定時巡檢的完整微學習閉環。

## 🏗️ 四階段宏觀進程 (4-Stage Architecture)

```
┌────────────────────────────────────────────────────────┐
│ Stage 1: 診斷定位與藍圖規劃 (Diagnostic & Blueprint)      │
│ 考綱難易度評估 ➔ 雲端進度總表 (Syllabus) ➔ 錯題本初始化 ➔ 摸底測驗│
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│ Stage 2: 模組化觀念打底與每日微學習 (Daily Micro-Learning)│
│ 白話自學講義 ➔ 二合一練習答案卷 ➔ 80分精熟分流 ➔ 週末全真週測驗 │
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│ Stage 3: 主題式題庫攻堅與錯題間隔重複 (Topic Sprints)    │
│ 弱點專案精刷 ➔ 歷屆真題剖析 ➔ 錯題本第一次全量清洗      │
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│ Stage 4: 全真計時模擬考與考前總驗收 (Final Cleansing)   │
│ 全真計時模考 (50題/75分) ➔ 錯題二次終極清洗 ➔ 考前速記卡│
└────────────────────────────────────────────────────────┘
```

1. **Stage 1: 診斷定位與藍圖規劃 (Diagnostic & Blueprint)**
   - 分析考綱與學員基礎，建立進度總表（Syllabus）與雲端錯題記錄。
   - 進行摸底試題檢測，建立初始能力基準線。
2. **Stage 2: 模組化觀念打底與每日微學習 (Daily Micro-Learning)**
   - 每日發布白話自學講義與二合一實戰答案卷。
   - 實施 80 分動態門檻分流：及格推進次日進度；未達標自動生成專屬「弱點補強講義」並重測。
   - 週末固定進行 50 題全真階段性週測驗。
3. **Stage 3: 主題式題庫攻堅與錯題間隔重複 (Topic Sprints & Spaced Retrieval)**
   - 針對弱點科目實施專題攻堅（每日 40 題）與歷屆公告真題深度解析。
   - 啟動錯題本全量清洗，透過間隔重複機制強制重測歷史易錯點。
4. **Stage 4: 全真計時模擬考與考前總驗收 (Full-Length Mocks & Final Cleansing)**
   - 嚴格比照正式考制（50 題 / 75 分鐘）執行 3 回全真計時模擬考。
   - 執行錯題終極驗收，確保連續達標，並產出考前高頻速記卡與公式對照表。

## ⚙️ 核心特色與防護機制

- **雲端整合 (Google Workspace Integration)**
  - 自動於雲端硬碟建立單元資料夾、進度總表 (Google Docs) 與錯題本 (Google Sheets)。
- **二合一合體檔案 (2-in-1 Practice & Answer Sheet)**
  - 將作答回饋表格、心得提問區與題目全文整合成單一文件，避免文件散落。
- **雙軌作答辨識與自動謄寫 (Dual-Track Auto-Transcription)**
  - 支援學員於頂部表格填答，亦允許直接在題幹旁作答或標註；系統自動將筆記與答案謄寫至頂部表格。
- **確定性程式化選項洗牌協議 (Deterministic Shuffling Protocol)**
  - 透過 [scripts/shuffle_options.py](scripts/shuffle_options.py) 執行確定性隨機洗牌，強制達成 A/B/C/D 正解均勻分佈，並嚴格檢驗避免連續 3 題相同選項，徹底消除 LLM 位置偏誤 (Position Bias)。
- **純淨排版與零 $ 符號規範 (Zero-Dollar-Sign Policy)**
  - 杜絕原始 LaTeX 與 `$` 符號排版，公式與變數全面採用乾淨純文字與 Unicode 符號（如 μ、σ、Σ、IQR），避免跨平台解析亂碼。
- **對話式生活化白話講義與漸進式名詞鷹架 (Progressive Scaffolding)**
  - 抽象公式逐一拆解人話對應並附帶日常數字手把手計算；新專有名詞強制搭配生活化譬喻，並建立文末名詞解析庫與錨點連結。
- **排程定時巡檢 (Daily Check-in)**
  - 支援定時自動巡檢答案卷填答狀態，已作答自動批改回饋，未作答則溫和提醒並支援彈性順延。
